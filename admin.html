Publishing

Two ways to save your work.
1 — Download. “Download content.json” saves the file to your computer; upload it to the repository yourself. This always works.
2 — Publish directly. Paste a GitHub personal access token below and the panel writes the file straight to the repository. The website updates within a minute or two.
Your token is stored only in this browser, on this device. It is never part of the website and never sent anywhere except GitHub. Anyone with the token can change the repository — treat it like a password, and revoke it on GitHub if this computer is lost.

Panel passcode
